# AniTrack — Каталог и трекер просмотра аниме

Веб-приложение для поиска аниме, отслеживания расписания выхода новых серий и ведения персонального списка просмотра с регистрацией аккаунта и облачным хранением данных. Реализовано на чистом JavaScript без сторонних UI-фреймворков и библиотек для работы с DOM.

## Демо
- **Рабочая версия (GitHub Pages):** [https://username.github.io/anitrack/](https://username.github.io/anitrack/) *(ссылка станет активной после деплоя ветки `main`)*

## Основной функционал
- **Система аккаунтов (Регистрация и Вход):** создание учётной записи через google, авторизация с выдачей JWT-токена сессии, выход из аккаунта и валидация форм нативными средствами браузера.
- **Облачное хранение списков (`PostgreSQL` / `Supabase REST API`):** персональная библиотека каждого пользователя хранится в облачной базе данных с разграничением прав доступа (Row Level Security) — списки синхронизируются между устройствами без использования `localStorage`.
- **Каталог и поиск в реальном времени:** просмотр популярных онгоингов и живой поиск с `debounce` и отменой устаревших сетевых запросов через `AbortController`.
- **Два источника данных:** переключение между **AniList GraphQL API** и **Jikan REST API v4** с автоматическим переходом на локальный резервный каталог при сбое сети.
- **Расписание и трекинг прогресса:** расписание серий по дням недели, статусы («Смотрю», «В планах», «Просмотрено», «Брошено»), личные оценки от 1 до 10, экспорт и импорт базы в `.json`.

## Технологический стек
- **HTML5:** семантическая разметка, шаблоны `<template>`, нативные модальные окна `<dialog>`, встроенная валидация форм (`required`, `minlength`, `type="email"`).
- **CSS3:** адаптивная сетка CSS Grid и Flexbox, CSS Custom Properties (переменные темы).
- **Vanilla JavaScript (ES6+ Modules):**
  - **Нативный DOM API:** `querySelector`, `createElement`, `cloneNode`, `DocumentFragment`, делегирование событий (`addEventListener` + `closest()` + `dataset`), безопасный вывод текста через `textContent`, `FormData` и `Constraint Validation API`.
  - **Браузерные Web API:** `Fetch API` (REST и GraphQL), `AbortController`, `Blob`, `FileReader`.
- **BaaS (Backend-as-a-Service):** Supabase Auth (JWT-аутентификация) + PostgreSQL REST API.
